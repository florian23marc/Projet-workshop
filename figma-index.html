Guide d'import Figma

Comment importer dans Figma

  1. 1 Installez le plugin html.to.design dans Figma (Figma Community)
  2. 2 Ouvrez chaque page HTML dans Chrome (ex: file:///C:/Users/flori/Documents/Projet workshop/index.html)
  3. 3 Lancez html.to.design depuis Figma et entrez l'URL locale ou utilisez l'extension Chrome pour capturer la page
  4. 4 Chaque page génère un frame Figma séparé. Renommez-les par ordre : 01-Home, 02-Login, etc.
