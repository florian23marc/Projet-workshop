# SkillSwap — Prototype Symfony API + React (Vite)

Ce dépôt contient un scaffold minimal pour démarrer rapidement le projet SkillSwap :

- `backend/` : skeleton Symfony orienté API (fichiers de configuration et controllers prêts). Exécutez `composer install` puis `symfony server:start`.
- `frontend/` : application React bootstrapped avec Vite. Exécutez `npm install` puis `npm run dev`.

Important : ce repo contient les fichiers de démarrage. Vous devez installer les dépendances localement (`composer`, `npm`). Voir README dans chaque dossier pour les commandes.
